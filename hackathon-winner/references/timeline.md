# Time Plans by Event Length

The split that winners keep converging on, regardless of length:

| Block | Share of total time | Goal |
|---|---|---|
| Idea + sponsor talks + demo script | ~10% | One problem, one solution, demo script, tracks chosen |
| Skeleton | ~15% | End-to-end path works, ugly is fine |
| Deepen the core | ~50% | Make the happy path solid, add max 3 features |
| Last stretch | ~20% | Freeze, deploy, backup video, slides, submission |
| Rehearse | ~5% | Timed run-throughs out loud |

Hard rule: at every checkpoint ask, "Could we demo right now?" If not, stop adding features.

## 7-hour event

| Clock | Block |
|---|---|
| 0:00–0:40 | Walk sponsors, pick idea, write demo script. No debating past 0:40. |
| 0:40–1:45 | Skeleton end to end |
| 1:45–5:15 | Core path + 1–2 features. Checkpoint at 3:00 and 4:15. |
| 5:15–6:30 | Code freeze at 5:15. Deploy, record backup video, slides, submit. |
| 6:30–7:00 | Rehearse twice, timed |

## 24-hour event

| Clock | Block |
|---|---|
| 0–2.5h | Sponsors, problem validation, idea scoring, demo script |
| 2.5–6h | Skeleton end to end |
| 6–19h | Core + features. Checkpoints every 3–4h. Sleep in shifts. |
| 19h | Code freeze |
| 19–23h | Deploy to target platform, backup video, slides, README, submission form |
| 23–24h | Rehearse 3+ times, prep Q&A answers |

## 36–48-hour event

| Clock | Block |
|---|---|
| First 10% (4–5h) | Sponsors, idea, demo script |
| Next 15% (6–7h) | Skeleton |
| Middle 50% | Core + features, checkpoints every 4h, everyone sleeps at least once |
| Last 20% | Freeze, deploy, video, slides, submission |
| Final 5% | Rehearse + Q&A drill |

## Multi-week online event (e.g. 3–6 weeks)

- Week 1: problem validation, talk to real users or sponsor reps, demo script, skeleton.
- Middle weeks: one shippable increment per week. Keep the demo always working.
- Final week: polish, the submission video (often the main judged asset and the thing organizers share afterwards), README, repo hygiene.
- Submit a day early. Late submissions are the most common avoidable loss.
